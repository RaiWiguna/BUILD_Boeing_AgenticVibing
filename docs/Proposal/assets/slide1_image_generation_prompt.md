# Slide 1 Image Generation Prompt

Use this prompt to generate the visual asset for slide 1 of the ATC FlowLens pitch deck.

## Prompt

Create a clean 16:9 presentation visual asset for an aerospace runway safety pitch deck. The scene should show a simplified top-down airport runway map with an aircraft icon on final approach and an airport rescue/firefighting vehicle crossing the same active runway. Use a Boeing-inspired blue and white palette: deep navy runway, crisp white runway markings, pale blue airport surface, electric blue taxiway guide lines, amber emergency vehicle, and a red conflict-risk line.

The visual must feel like a professional ATC decision-support interface, not a generic futuristic illustration. Make it flat, technical, readable, and suitable for a PowerPoint/web pitch deck. Include a clear alert callout panel on the lower-right that says "Conflict window" with high-contrast red heading and dark navy body text. The callout should explain that the aircraft is cleared to land while an airport rescue vehicle is crossing the same runway. Add a small label near the lower-left that says "RWY 27 active operation".

Use an aircraft icon that is clearly recognizable from above, not a realistic photo. Use a simple ARFF vehicle icon/shape with visible wheels. The layout needs enough negative space and clean geometry so it remains readable when placed on the right side of a pitch deck cover slide. Avoid logos, brand marks, manufacturer names, realistic airline liveries, people, cockpit interiors, stock-photo style, dark unreadable text, neon cyberpunk effects, and decorative blobs.

## Negative Prompt

No Boeing logo, no airline logo, no brand mark, no photorealistic crash, no flames, no disaster imagery, no human injury, no crowded airport terminal, no cockpit dashboard, no generic AI purple glow, no unreadable tiny labels, no low-contrast alert text, no abstract 3D objects.

## Style Notes

- Aspect ratio: 16:9
- Primary use: slide 1 right-side visual asset
- Mood: aviation safety, calm urgency, technical clarity
- Palette: navy, Boeing blue, white, pale blue, amber, red
- Text that must remain readable: "Conflict window" and "RWY 27 active operation"
- Preferred composition: top-down runway map, aircraft near upper runway, ARFF vehicle crossing mid/lower runway, alert callout in lower-right
