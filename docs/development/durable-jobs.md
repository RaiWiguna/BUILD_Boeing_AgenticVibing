# A06 — Durable jobs dan accepted-result coordinator

Tanggal: 9 Oktober 2026. A06.1–A06.2 selesai sebagai platform mandiri dengan AnalysisModule fake melalui frozen ports. [Evidence](../testing/a06-evidence.md). Contract1.0.0 tetap; bukan integrasi B/provider atau G-BE.

Host `create_host` menerima trusted `analysis_module`, `job_policies` (StagePolicy) dan `repository_factories` dengan namespace analysis.*. Default tidak mengaktifkan jobs/domain module; configured jobs memerlukan DB/source storage. Test composition berlabel MOCK, readiness tetap HOST_ONLY503. Tidak ada import internals B. Registered policies menetapkan stage/version, effective RunConfig (model/API/SDK/prompt/reducer/rule versions), readiness, granular cloud rights, output type→repository, acceptance handler, reservation, concurrency, lease dan max attempts. Config request wajib sama dengan registry; worker/model tidak memilih authority. Handler biasanya bound AnalysisModule.accept; validate/accept lewat frozen interfaces. Readiness/accept callbacks harus bounded local checks/writes, tanpa provider call.

Run dibuat dengan human analysis/read (+audio untuk input audio), explicit source rights, selected source/asset IDs, budget, deadline, expected_revision dan Idempotency-Key. Captured as-of, source revision/hash, effective config/policy fingerprints dan creator credential_version durable. Reanalysis menghasilkan run baru; retry key identik memberi original creation receipt, changed payload conflicts. Eligibility selalu membaca creator active/version/current grants, latest input, current source local/cloud_audio/cloud_context dan retention. Readiness harus benar pada create/claim; declaration tidak membuktikan provider smoke.

Migration platform.0012 menambah detailed runs/jobs/attempts/run requests/cancel receipts di atas frozen relational foundation. Worker claim single API-owned SQLite UOW: server memilih queued/retry job, satu attempt/lease/scope dengan source/asset allowlist, AS_KNOWN dan reservation. Stage concurrency global dibatasi1–16, max attempts1–3, lease100ms–120s dan deadline maksimum24h; scope expiry tidak melewati lease/deadline/worker expiry. Heartbeat memperbarui durable lease dan scope; caller tidak bisa memperpanjang sendiri. Active job guard berlaku pada permissions/repositories/source/evidence/assets, termasuk cached contexts; operator-bound scope tanpa actual active attempt ditolak saat coordinator terpasang.

Reaper berjalan pada startup, lease polling, authorized run inspection atau explicit Jobs.recover. Expired/revoked/stale/deadline attempts ditutup, scope direvoke dan reservation dilepas; lost response/cancelled outstanding attempt dibebankan konservatif sebesar reservation karena biaya provider tidak diketahui. Eligible retry memakai backoff1s×attempt + jitter0–500ms, maksimal2 tambahan; semantic/budget/rights/version failures tidak retry. Reported accepted cost <=reservation; unused reservation dilepas. Unknown cost tetap unknown pada Usage, tetapi charged ledger memakai full reservation. Aggregate usage mempertahankan unknown dari lost attempts. Ini idempotensi commit lokal, bukan exactly-once billing provider. Idle API tanpa polling tidak mempunyai timer reaper mandiri; authority tetap menolak expired lease sebelum akses/commit.

Public routes: POST `/api/v1/sessions/{id}/analysis-runs` (202), GET `/analysis-runs/{runId}`, POST `/analysis-runs/{runId}/cancel`. Create JSON <=64KiB; cancel <=4KiB dengan expected_version dan key. Cancel memakai optimistic run version; retry identik stabil, changed version/key payload conflicts. Cancel menutup pending/active jobs dan menjaga accepted results. Semua routes cookie/Origin/CSRF/no-store sesuai A03; inspection memerlukan analysis grant.

Internal worker bearer routes: POST `/internal/jobs/lease` (stage <=4KiB), `/{jobId}/input`, `/heartbeat`, `/cancelled` (JobLease <=16KiB), `/results` (JobResult <=1MiB). Browser cookie/origin dan caller context claims ditolak. Lease response hanya frozen lease + opaque scope_id; input mencakup server context/effective config, selected audio metadata/hash/clock, dan hanya AS_KNOWN observed records untuk cloud_context policy (<=512 dan response<=1MiB). Audio-only consent tidak mengirim context records. Tidak ada private storage path, credential, truth atau seluruh inventory. Scope dipakai pada private media/artifact routes A05. Worker executable, remote port adapter dan SDK processing tetap B.

Result flow: strict copied-model validation, canonical output_hash (`result_hash`: outputs/evidence/artifacts/status/usage/failure_code), exact owner/lease/run/revision/input/config, active deadline/budget/live rights; verify actual evidence scope/hash/quote/time/source file and staged artifacts. Module.validate berjalan di luar writer lock; hasil validation tidak boleh mengubah idempotent candidate/routing/usage, lalu semua checks diulang dalam final UOW. Worker transcript available_time harus unknown (tidak dibuat historis), event_time=end, channel/range/audio anchors valid; MOCK origin hanya test profile. Pending quote dapat merujuk transcript dalam candidate yang sama dengan backing audio tervalidasi; ini tidak memberi cloud_context atau raw audio access tambahan.

Registered accept handler tidak boleh commit/rollback/raw COMMIT; caught attempts membuat transaction rollback-only. New output IDs harus belum ada, setiap output dibaca kembali dari registered repository dan harus identik typed DTO. Domain writes, evidence registry, accepted artifact registration/flag, audit, budget/usage/state, immutable receipt dan monotonic JobProgress event berada pada satu UOW. Failure rollback seluruh efek SQL; durable candidate bytes tetap pending untuk retry/TTL. Accepted bytes sudah fsynced/sealed pada A05, sehingga acceptance hanya atomik SQL, bukan transaksi SQLite+filesystem. Tidak ada second unverified file promotion.

Same owned result request mengembalikan original receipt, termasuk sesudah lease selesai/expired atau publication failure, tetapi live principal/source/creator/config checks tetap berlaku. Changed request conflicts. Concurrent identical result yang selesai saat validation/context creation berlangsung membaca ulang immutable receipt tanpa mengaktifkan scope lama. Publication hanya after commit/outside lock; failure durable, receipt.sequence menunjuk event yang bisa dibaca ulang. Actual WS resync/snapshot A07 belum dibangun. Failed provider result menyimpan failure/usage/receipt/event tanpa domain outputs/evidence/artifacts, lalu eligible bounded retry; partial status disimpan eksplisit.

Semantik domain, provider fidelity, entity association/interpretation dan original recording timestamp authenticity tetap di luar pembuktian platform fake. No provider calls, real private corpus, production/deployment, frontend, G-BE atau domain validation. Full-size resource/performance, physical power loss, maintenance purge/backups, real adapters dan real B integration belum dibuktikan. Selanjutnya A07 memerlukan instruksi baru; scope request berhenti setelah A06.
