# Geometri observed Paket A

A08.1 menyediakan kernel numeric `flowlens.geometry.kernel`; `GEOMETRY_VERSION=footprint-xy-1`. Input Track frozen yang dinormalisasi dalam meter dan Layout source-metadata-1. Pose/shape calculation tidak mengimpor evaluator labels/schedule, tidak mengubah source, dan tidak memanggil B/provider. Context/evidence/observed-predicted intervals/eligibility serta GeometryReader port tersedia pada A08.2; rules/alert lifecycle tersedia pada A08.3.

## Frame, footprint dan resources

Frame canonical LOCAL_CARTESIAN memakai X/Y meter, heading0 sepanjang +X,90 sepanjang +Y, counterclockwise. Konvensi ini cocok dengan fixture independent-1/fictional-1 dan source historis2660222 (`atan2(dy,dx)`), bukan implicit geographic/compass adapter. Track.heading_deg valid0≤h<360. Incoming compass/WGS84 memerlukan adapter teruji sebelum menjadi canonical Track; kernel tidak mengarang proyeksi. Layout m/ft dinormalisasi oleh existing Layout.metric (exact0.3048 conversion), sedangkan fields Track `*_m` sudah canonical meter.

Footprint rectangle memakai length pada heading dan width melintang, lalu rotation/translation seluruh vertices; center bukan proxy clearance. Cardinal angles memakai exact basis untuk menghindari epsilon palsu pada tangent. Polygon validity/nonzero finite area diperiksa setelah transform. Boundary contact termasuk occupied. Local numeric envelope centre/layout coordinates ±10,000,000m dan dimensions/margin≤100,000m; out-of-range, collapsed shape atau hold segment≤1e-9m menghasilkan NOT_EVALUABLE, copied invalid DTO INVALID_INPUT. Envelope adalah batas perhitungan, bukan batas operasional aircraft.

Runway polygon tetap nominal. Protection geometry adalah explicit mitered offset sebanyak configured lab margin + layout spatial uncertainty, termasuk conservative corner extension; parameter/version disimpan oleh caller berikutnya. Source polygon tidak diperbaiki diam-diam dengan buffer0. Layout version/validity harus cocok pose. Hold line memerlukan allowed-side reference point eksplisit yang tidak berada pada line; finite lateral corridor memotong footprint sebelum signed-distance classification BEHIND/TOUCHING/STRADDLING/BEYOND/OUTSIDE_SEGMENT. Tidak menebak arah larangan dari urutan endpoints atau clearance text.

## Swept movement model

Dua poses wajib satu session/run/revision/source/hash/entity/layout/dimensions, identity diketahui, dan event time strictly increasing. Constant heading + linear centre translation memakai convex hull footprints: exact untuk model itu, sehingga endpoint clear tidak menyebabkan tunneling. Stationary pose tetap memiliki footprint. Perubahan heading memakai circumscribed half-diagonal disk sepanjang linear centre path; buffer64 vertices dikompensasi terhadap inward polygon approximation. `Sweep.exact=False`/LINEAR_ROTATION_BOUND mempertahankan conservative possibility; endpoint hull saja tidak cukup untuk rotating corner. Changing dimensions/ambiguous links ditolak, bukan dipaksakan menjadi movement.

`crosses_hold` memerlukan movement dari allowed/touching menuju straddling/beyond dan finite segment intersect oleh sweep. Numeric interpolation/bound bukan bukti empiris path lengkap di antara samples; gaps, stale/unknown clock/coverage/identity serta predicted-vs-observed labels ditangani oleh reader A08.2. Source permissions/operational clearance tidak diciptakan oleh polygon intersection. Synthetic technical checks belum domain/operational validation.

## Observations, predicted timing and access

A08.2 exposes `Occupancy.observations(RequestContext, entity_id) -> GeometryResult` through the frozen port. `report` adds separate `observed`, `predicted`, `observed_at_ms`, last observed occupancy, ETA/exit, unknown flags, resource and config_hash. REST `GET /api/v1/sessions/{session_id}/entities/{entity_id}/geometry` supports view/mode/run_id/resource; it issues context from authenticated playback Controls, never caller-supplied scope/time. Default resource RUNWAY; PROTECTION includes declared margin and layout uncertainty. [Acceptance evidence](../testing/a082-evidence.md).

`observed` combines discrete source footprints and explicitly linear fixed-heading interpolation between valid samples; it is clipped at cursor+1. `predicted` assumes latest eligible speed/heading held constant, default horizon30s, then clips at layout/identity expiry. Heading changes between samples cannot certify occupancy timing and remain NOT_EVALUABLE. ETA/exit are absolute session milliseconds for the central model; exit=None/exit_unknown when occupancy persists through the horizon. Integer intervals conservatively include contact using floor and ceil+1. Clock uncertainty, track age/lag, configured temporal margin and layout uncertainty/speed expand timing. These margins do not constitute a covariance or certified physical model.

Policy is immutable, finite and bounded; version occupancy-1 and hash bind kernel version, declaration and resource. Known zero speed keeps future motion unknown even when currently outside. Unknown/stale/gap/identity/layout/quality cases return explicit NOT_EVALUABLE and occupied=None; last_observed_occupied can retain an earlier occupied pose. Future declared coverage gaps make prediction unknown. GeometryResult.intervals is the union of model-observed/predicted intervals for port compatibility; use OccupancyReport to inspect origins/unknown flags. No result implies operational clearance. Shared-resource labels distinguish observed-model overlap, predicted-model overlap, UNKNOWN and NO_MODELED_OVERLAP, never SAFE. Opposite headings and crossing/arrival use the same polygon resource.

Pure geometry runs outside the writer transaction. Final live context/source rights checks and server-derived evidence indexing share one atomic UOW; every anchor can be resolved/get again under current source hash/scope/time/access. Cached refs give no additional source rights. Arbitrary evidence registration still requires analysis/review authority. No analysis/provider invocation occurs in this reader.

## Source-observed lab rules and alert revisions

A08.3 adds `Rules.evaluate` over actual Sources, canonical source evidence and A08.2 eligibility/timing. It interprets only strict registered `lab-source-1` JSON in SourceEvent.statement: INSTRUCTION actions/explicit source-event relationships, INSTRUCTION_COVERAGE and SOURCE_ALERT records, plus separate AUDIO_ACTIVITY measurement annotations. Unknown/plain radio text is unavailable as structured authority; no NLP/intent extraction or B finding assembly occurs. Source relationships are entity/source scoped. A new explicit instruction relationship can supersede an earlier instruction; cancellation/report never removes observed physical footprint. Missing coverage/ambiguous records/profile/clock/layout/identity/stale/gap conditions preserve UNKNOWN rather than asserting no clearance or clear runway. [Evidence](../testing/a083-evidence.md).

Default RuleProfile lab-rules-1 applies only to fictional-1, H1 allowed side(-50,0), protection margin5m and response window5000ms. It has LAB_ONLY applicability; partner/public-corpus geometry profile is unavailable by default. Shared resource rules use A08.2 source-bound predicted intervals, clock margins and identity/layout limits. HOLD_SHORT ordering abstains when instruction/track clock bounds overlap; missing frame clock/layout/identity remains NOT_EVALUABLE. Observed and predicted-model overlap remain labelled; zero-speed/exit/dropout uncertainty is retained. Rule versions/config hashes and evidence are output metadata; INFO/NOTICE/ATTENTION are deterministic review priority, separate from source INFO/WARNING/CRITICAL severity. Thresholds are synthetic, not operational SOP.

Migration0015 stores per-session/revision/run/mode evaluation head, append-only alert revisions and immutable publication/seen receipts. Publication requires current analysis/review authority (worker excluded), key/expected head version, and a cursor at or after the last committed publication; it atomically appends changed revisions, updates head, emits RulePublished with indicator values, audits and stores receipt. Duplicate key returns prior receipt after live authority/evidence recheck; mismatched key input/version or stale version conflicts. Scope/as-of reads preserve earlier history. Source alert versions can change only from their recorded source state/severity; contradictory same-time records retain source variants and UNKNOWN. Acknowledgment is SEEN_ONLY for a specific revision, not an authority/severity/status change. Canonical evidence caching during reads is separate from authoritative publication.

REST paths under `/api/v1/sessions/{session_id}`: GET `/rules` returns signals/indicators and current evaluation_version/last_published_as_of_ms; POST `/rules/evaluations` publishes with `{key,expected_version}`; GET `/alerts` pages with limit1–100 and after UUID, GET `/alerts/{id}/history` with after_version and next_version; POST `/alerts/{id}/seen` uses the same mutation body; GET `/indicators` reads metrics. All use authenticated server Controls.context with view/mode/run_id, no arbitrary RequestContext/as-of payload; POST requires CSRF and strict4KiB JSON. Scope is rechecked for every page/history/receipt. Publication is an explicit API operation; no background detector/provider daemon is introduced. Local outbox marker/seen DTOs fall back to frozen WS resync; fetch scoped REST alerts/indicators after resync. Frozen source/snapshot/WS1.0.0 is unchanged.

`lab-indicators-1` is EXPERIMENTAL_NOT_WORKLOAD. Source-reported synthetic-active-audio-1 annotation intervals are unioned per60s view window, never inferred from transcript duration; reporting does not verify VAD/channel overlap and occupied_audio_ms stays null. Active_entity_count means eligible latest geometry observation, unknown_entity_count means ineligible geometry entity. Optional frozen ContextReader.lookup(get_active_rule_context,limit100) supplies OpenLoop records; unavailable callback/count coverage stays unavailable/partial and at most100 results are inspected, duplicate loop IDs count once/conflicting IDs abstain, and every included loop/evidence is scoped/time checked. Queue/running counts use the current coordinator, explicitly not historical replay measurements. Publishing persists indicator values, so a duplicate receipt/restart does not silently recount. These metrics do not assess mental state, fitness or operational workload.
