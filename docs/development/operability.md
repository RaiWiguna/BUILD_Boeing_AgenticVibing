# Operability lokal Paket A

A09.2 menyediakan health/readiness/release, dedicated structured logs, admin provider metadata/diagnostics, disk probes dan usage/budget aggregation. B masih berupa fake registered frozen ports. Backup/isolated restore/maintenance CLI adalah A09.3; delivery, real SDK checks dan integrated release tetap tahap berikutnya.

`/health` melaporkan process liveness. `/ready` menghasilkan `scope=LOCAL_PLATFORM` dan dependency statuses aktual untuk schema/DB, import/raw/artifact/journal roots, replay, coordinator dan retention. DB checksum manifest/quick_check serta actual write diuji (write di-rollback); private-root probes menulis/fsync/unlink file opaque dan memeriksa disk available. Coordinator memeriksa identity DB dan ledger reservation/charge invariants. Missing, corrupt journal, low disk atau failed storage write memberi 503 dengan code terbatas tanpa paths/error text. Full configured local host dapat memberi 200 meski cloud adapter unavailable. `integration_gate=NOT_STARTED` dan `provider_verified=false` tetap terpisah; local 200 bukan production/domain/provider acceptance.

`FLOWLENS_MINIMUM_FREE_BYTES`/`HostSettings.minimum_free_bytes` memberi threshold setiap private root (default64 MiB; proposal engineering lokal). Admin `GET /api/v1/admin/disk` mendapat free/total byte counters dengan labels roots, tanpa private paths. Probes tidak menghapus data sesi. API auth/account/grants tetap diperlukan untuk source access; readiness bukan bypass authorization.

`/release.json` memuat installed dependency versions, current migration manifest, actual reducer/kernel/lab rule template/layout versions serta validation/gate labels. Optional `FLOWLENS_RELEASE_SHA` dan `FLOWLENS_LOCK_SHA256` menerima hash metadata terikat format; origins jelas OPERATOR_DECLARED/UNRECORDED. Null berarti tidak direkam, bukan verified release. Endpoint tidak membaca/export credential files, environment dump, source contents atau paths; container digests/browser/domain/provider benchmarks belum dibuktikan oleh unit lokal ini.

Launcher `python -m flowlens.api.serve` mengaktifkan dedicated `flowlens.ops` JSON INFO sink dan tetap mematikan access payload logs/reload/multi-worker. Events hanya menerima bounded typed whitelist: HTTP generated request ID/status/latency sampai headers; committed job session/run/job/attempt IDs, stage, config/input hashes dan ledger charge. Bodies, query/path/header/cookie/credentials, transcript/prompt/audio dan exception text tidak menjadi field. Job events dijalankan after_commit sehingga rollback/duplicate result tidak mencetak completed attempt lagi. Handler failure tidak membatalkan accepted commit. Tidak ada application-managed log file/30-day rotation claim; operator mengatur sink/retention pada tahap delivery. SDK debug logging tidak diaktifkan.

Admin provider endpoints: GET/POST `/api/v1/admin/provider-profiles`, GET `/{id}/history`, POST `/{id}/checks`. Strict duplicate-free JSON maksimal16 KiB, same-origin/CSRF dan live admin berlaku. Profile versions immutable, expected_version/idempotency/hash dan ops audit/receipt transactionally persisted; bounded100 profiles/32 versions/100 diagnostics per version. Input memakai frozen ProviderProfile dan local declared ProviderOptions: project/recognizer IDs, word timestamp request, adaptation version reference, terms mode dan opaque credential_ref. Tidak menerima key/file path/URL/transcript atau actual adaptation phrases; common credential signatures ditolak. Source rights dan terms enforcement tidak dilemahkan hanya karena admin menyimpan metadata.

`create_host(provider_adapters={...})` menerima explicit AdapterBinding memakai frozen ProviderAdapter. MOCK hanya test profile; root/profile/check origin dilabeli MOCK. B check dipanggil dengan frozen metadata di luar DB lock; actual network/SDK implementation dan timeout behavior milik B. Binding options harus sama dengan declared options, dan result tidak boleh mengubah configuration/identity; final commit mengulang live admin/revision checks. Errors memakai bounded failure codes, tanpa raw provider exception/response. New configuration resets UNVERIFIED. Semua hasil tetap `provider_verified=false`; real adapter report hanya ADAPTER_REPORTED, bukan benchmark/provider certification. A tidak mengganti registered StagePolicy config/runs historis secara otomatis, tidak memilih provider fallback, dan tidak memanggil transcribe/extract saat diagnostic.

`GET /api/v1/admin/ops-audit` membaca bounded paginated metadata profile actions (maksimum100). `GET /api/v1/admin/usage` mengagregasi retained local runs. `/api/v1/sessions/{sid}/usage?run_id=...` memakai server context, current revision dan analysis capability. Budget/reserved/used/remaining berasal dari ledger per attempt; duplicate results tidak double count. Reported Usage tetap null bila unknown, berbeda dari conservative reservation charge. Summary memberi counts per stage/job state, unreported/active attempts, eligible queue wait dan measured lease age (historical attempts tanpa timing tetap unknown). Frozen Usage tidak mempunyai per-channel billing breakdown, sehingga channel attribution ditandai NOT_REPORTED_BY_FROZEN_USAGE, bukan membagi/menebak audio usage. Totals bukan provider invoice; purged source/run data tidak diklaim masih masuk lifetime account billing totals. Domain unknown/false-finding/evaluator metrics dan actual provider quota/latency diagnostics tetap B/evaluation scope.

Evidence: [A09.2](../testing/a092-evidence.md). Synthetic/fake results tidak membuktikan Google/Gemini access, domain review, operational validity atau release gates.
