# A05 — Private assets dan evidence registry

Tanggal: 9 Oktober 2026. Platform A05 selesai; contract 1.0.0 tetap. [Evidence](../testing/a05-evidence.md). Tidak ada integrasi B/provider.

`Assets` mengimplementasikan frozen AssetAccess: raw bytes hanya dari source package privat immutable, file size/SHA diperiksa sebelum streaming, permission/source rights/retention dicek lagi per chunk. Public GET/HEAD `/api/v1/assets/{assetId}/audio` memakai cookie principal dan audio grant; single byte range explicit/open/suffix, 206/416, ETag dan If-Range, no-store. Internal route yang sama memakai worker bearer dan scope allowlist. Private path/key tidak dikirim. Port download dibatasi16MiB; HTTP stream tidak memuat seluruh file. Revocation setelah headers dapat memutus stream; partial bytes yang sudah dikirim tidak dapat ditarik kembali.

Optional `FLOWLENS_ARTIFACT_STAGING_PATH` terpisah dari raw/staging/database. PUT `/internal/artifacts/{id}?scope_id=...` menerima X-Artifact-Metadata (ArtifactSubmission JSON <=16KiB) dan raw body melalui bounded queue. Worker saja, max64MiB/candidate dan32 pending/worker; WAV/FLAC actual decoder, size/SHA/channel/duration, source/derivative range dan registered transform version diperiksa. Candidate fsynced/sealed sebelum SQL registration; identical scoped retry stabil, TTL paling lama24h dan tidak melampaui retention sumber. Startup verifies durable inventory dan membersihkan expired pending/orphans. A06 harus mempromosikan accepted flag/artifact registration dalam result UOW. Fidelity transform/FFmpeg tetap B; laporan/export/purge/backups A09. Submission bukan accepted domain result.

`EvidenceRegistry` mengimplementasikan EvidenceService. Resolve/register memeriksa context proof, session/run/revision, live source rights/hash, as-of, stable source event/track ID, audio mapping/actual file integrity dan bounds, transcript record/source/audio anchors, serta exact quote/span. Available time unknown/future ditolak pada AS_KNOWN; tidak diciptakan historis. Transcript readers boleh memverifikasi backing audio tanpa memperoleh raw bytes/audio grant. Unsupported POLICY atau references tanpa registered adapter menghasilkan EVIDENCE_UNAVAILABLE. Domain semantics tetap B; resolve tidak membuktikan kebenaran ucapan/interpretasi.

Registry rows immutable (migration platform.0011); register memakai UOW caller dan rollback seluruh insert tanpa commit. Pending transcript validation tersedia sebagai trusted coordinator hook, bukan input context browser. Analysis repositories hanya lewat frozen injected ports. A06 harus mengikat worker contexts ke actual active attempts; standalone operator-bound worker scope A03 belum merupakan lease.

No persistent runtime, frontend, provider call, B implementation, operational/domain validation. Readiness tetap HOST_ONLY503 dan semua release gates not_started.
