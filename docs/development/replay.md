# Observed replay Paket A

A07.1 tersedia; controls dan REST/WS masih unit berikutnya. `flowlens.replay.snapshots.Replay` memakai real `Sources` dan optional satu `ModuleRegistration.snapshot_reader` atau `AnalysisModule.snapshot` melalui frozen port. Host mengaktifkannya hanya ketika committed source storage tersedia. Tidak mengimpor internals B atau evaluator schedule/labels; tidak memanggil provider/job pada snapshot.

Reducer `observed-replay-1` memeriksa scope/revision dan revalidasi copied DTO, mengurutkan `(event_time_ms, UUID)`, menerima duplicate identik dan menolak ID dengan payload berbeda. AS_KNOWN hanya memasukkan event time serta available time <= as-of; unknown availability tetap excluded. DEBRIEF memasukkan historical unknown/delayed availability dengan mode eksplisit, tetap membatasi event time. Quality mempertahankan missing/ambiguous/conflicting; empty snapshot MISSING.

Source event headers berasal dari committed A observations. Snapshot B yang mengandung source event wajib cocok dengan source aktual; memory/finding projections tetap milik B, harus exact context/run/revision/as-of/mode dan nested scope yang valid. Frozen `Snapshot.events: list[SourceEvent]` merepresentasikan header event track; geometri `Track` tetap tersedia melalui `SourceReader.tracks`, bukan hilang dari source atau ditambahkan ke shared wire tanpa version decision.

Migration `platform.0013` menambahkan derived `platform_replay_snapshots` tanpa mengubah checksum migration terdahulu. Cache key memuat reducer version, run, mode, input hash, hash seluruh observed source, analysis projection dan persisted session sequence. Nearest checkpoint <= as-of dengan key sama disusun kembali bersama eligible input; backward seek tidak membaca future checkpoint. Payload checksum/scope diverifikasi, cache rusak dibangun ulang. `snapshot(context, checkpoints=False)` memberi full rebuild oracle tanpa menulis checkpoint. Ini belum klaim percepatan/capacity A10.

Pembacaan pertama mengambil source dan sequence di authorized UOW. Callback snapshot B berjalan di luar writer lock agar bisa menggunakan ports. UOW akhir memeriksa kembali grants/session/revision/source rights, source rows serta sequence; perubahan concurrent menghasilkan VERSION_CONFLICT, caller dapat reload/retry. Cache tidak melewati live authorization. Persisted checkpoints bertahan saat owner SQLite restart; raw source tidak dimutasi. Cache adalah turunan disposable, bukan authority/audit atau B memory reducer.

## Durable controls dan compatibility

A07.2 `Controls` menyimpan satu shared row per sesi dan satu local row per actor. FOLLOW membaca shared cursor; LOCAL memakai row actor sendiri. Memilih view/run/mode membangun RequestContext di server dari live cookie/grants/revision dan posisi tersebut; raw client context tidak diterima. LEADER label hanya untuk pemilik leader aktif. LEAD/RELEASE/PLAY/PAUSE/SEEK/STEP/SPEED/ARCHIVE shared memerlukan review grant; local playback cukup read grant. Source reviewer rights tetap diperiksa setiap operasi. Claim dua pengguna memakai optimistic version; leader credential/grants diperiksa live sebelum takeover.

Play cursor dihitung dari anchor clock dan speed; seek/step pause, range dibatasi horizon audio/event/availability. Step AS_KNOWN menggunakan max(event time, available time), unknown availability excluded; DEBRIEF menggunakan event time. Kecepatan positif <=16× termasuk0.5/1/2. Controls tidak memanggil snapshot B, jobs atau provider. Local control tidak mempublikasikan posisi privat ke session event stream. Shared control/enqueued typed PlaybackState/audit/idempotency receipt/version berada dalam satu UOW. Receipt durable immutable; same key/payload/version memberi original result, changed payload conflict.

Archive menandai shared replay read-only dan paused; local viewing tetap tersedia. Startup `recover()` tidak auto-play; ia mempertahankan cursor terakhir yang committed, pause dan increment version. Hilangnya leader credential/grant juga berhenti pada cursor durable terakhir karena elapsed playback sesudah kehilangan authority tidak dapat dianggap sah. Ini bukan janji menyimpan posisi setiap tick atau simulator branching. Source observations tidak dimutasi oleh control/archive/restart.

`LegacyHistory` memakai audited alias string atau UUID eksplisit, cookie dan per-session read grant. Hanya status/counts/ordered sim_ms+sequence frame metadata keluar, maksimal100 frame. JSON metadata/public/private/events/commands quarantine tidak diproyeksikan. Historical availability tetap None; source_status NOT_EVALUABLE sampai provenance/clock/rights/unit eligibility tersedia. Tidak membuat observed rows atau klaim AS_KNOWN dari archive lama. Output snake_case mengikuti source audit (`sim_ms`, `session_id`), tanpa silent camelCase coercion. Training operator/seats/commands routes lama tetap absent/deprecated; historical command disimpan, tidak dieksekusi, bukan AI tool. Full legacy source/monitoring payload tidak direstorasi; disposition eksplisit metadata-only.
